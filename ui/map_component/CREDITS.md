# Map component credits

- `leaflet.js`, `leaflet.css`: [Leaflet](https://leafletjs.com) v1.9.4,
  BSD 2-Clause License. Stored here so the library is not loaded from an
  outside server.
- Map tiles are loaded at run time from Esri's public ArcGIS Online tile
  services, which need no API key: World Physical Map ("Map"), World Light
  Gray Base ("Light"), World Dark Gray Base ("Dark") and World Imagery
  ("Satellite"). None of these layers contains place names. The attribution
  shown on the map must stay visible. Check Esri's terms of use before any
  use beyond this demonstration.
