# Research notes

Collected using the templates in project brief §10.

## Interface references reviewed

### 1. GOV.UK Design System — Question pages
- URL: https://design-system.service.gov.uk/patterns/question-pages/
- Useful pattern: one question (or one small group) per page, with a single primary action. Adopted in the Selection screen.

### 2. ONS Service Manual — Showing uncertainty in charts
- URL: https://service-manual.ons.gov.uk/data-visualisation/guidance/showing-uncertainty-in-charts
- Adopted: only show a shaded band when the underlying statistic supports it; always pair the chart with a text sentence about uncertainty.

### 3. W3C WAI — Complex images
- URL: https://www.w3.org/WAI/tutorials/images/complex/
- Adopted: every chart has a short text summary and a data-table alternative.
